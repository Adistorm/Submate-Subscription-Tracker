## Agile Development and Version Control

Submate: Subscription Tracker follows an Agile development workflow using Git and GitHub.

### Feature: Subscription Management
- Implemented functionality to add, edit, and delete subscriptions.
- Added subscription categories, billing cycles, and renewal dates.
- Used browser local storage to persist subscription data.

### Version Control Workflow
- Created a feature branch: `feature/subscription-management`.
- Tracked source-code and documentation changes using Git.
- Used descriptive commit messages to maintain project history.
- Planned Pull Requests and code reviews before merging features into `main`.
- Included merge-conflict resolution as part of the version-control demonstration.
